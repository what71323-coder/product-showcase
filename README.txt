PROJECT TITLE: NovaStore - Premium Product Showcase

CHOSEN THEME:
An online product showcase displaying headphones, a wristwatch,
and wireless earbuds using HTML and CSS.

FEATURES IMPLEMENTED:
1. Responsive header with brand name and navigation links.
2. Hero section with heading, description, and CTA buttons.
3. Three product cards with descriptions, prices, and action links.
4. About section, contact section, and footer.
5. Separate external CSS stylesheet.
6. Flexbox and CSS Grid for page layouts.
7. Responsive layouts for desktop, tablet, and mobile screens.
8. Hover and focus-visible styles for interactive links and buttons.
9. Accessible color contrast and reduced-motion support.
10. Semantic HTML elements and descriptive meta information.

CSS EFFECTS USED:

1. Transition:
   Navigation links smoothly change color on hover.
   Buttons smoothly change background color and position.

2. Transform - translateY():
   Product cards move slightly upward when hovered.

3. Transform - scale():
   Product icons gently enlarge when the product card is hovered.

4. Transform - rotate():
   The decorative hero dot rotates when the hero visual is hovered.

5. Box Shadow:
   Product cards and buttons display smooth shadow effects.

6. Focus Visible:
   Keyboard users can identify the currently focused link or button.

HOW TO RUN THE PROJECT:
1. Keep index.html and style.css in the same folder.
2. Open index.html in any modern web browser.
3. No server, JavaScript, or external framework is required.

TECHNOLOGIES USED:
HTML5 and CSS3
